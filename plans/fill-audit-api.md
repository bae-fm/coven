# Appendix E conformance audit

Base: `0358aa5d57be35a66ebad325c9b96a4de62f559b` (the `origin/main` used to create `fill-audit-api`).

Decisions:

1. Re-export metadata/checksum, snapshot and filename types from their owners; an app must use the same identities as storage and pending records.
2. Preserve fresh-list omission: §4 and E5's `StorageCheck::List` explicitly permit it despite the earlier probe paragraph.
3. Preserve conditional-conflict retries: §4 and E5's pending policy require retrying fixed bytes despite the narrower `StorageError::retryable` comment.
4. Preserve worker-transfer bounds and conservative whole-table query tracking for unsupported predicates; removing either would risk invalid worker transfers or missed query updates.
5. Preserve the shared `ObjectPath` and `DeviceId` owners rather than invent facade copies; the path error depends on format ownership, and the spec leaves cross-crate opaque-id construction unspecified. Record their declaration differences explicitly.
6. Box filesystem/settings causes as declared, preserving their concrete native cause and bootstrap publication classification.

No choice introduces a protocol transition or Lean-model change. T21–T108 remain outside this change.
